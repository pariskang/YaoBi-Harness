# 自主追问：十问歌 × 骨科专科问诊

> **改动（本版）**：模型问出的问题**一律原样送达**。轴表、必答范围与题库全部改为
> **给模型的建议**：`axis_id` 填错或不填照原文问；必答轴模型没问不补题，下一轮再作为
> 建议提醒一次；问题里带推断照原文问；出现剂量只隐去数值。
> 此前的「提问已被拦下：必答轴被模型遗漏，已按题库补回」不再存在——它把模型真正拟的
> 追问换成了罐头问句，正好废掉了让模型问诊的全部意义。未闭合的必答轴仍然会让充分性
> 裁决判 `blocked`，但它拦的是**含剂量环节**，不是对话。

## 一句话

**模型决定问什么、怎么问、什么时候追下去；规则决定哪些必须问到；一个独立审核者决定什么时候可以停。**

这三者分开，是这一层唯一重要的设计。合在一起就会出现最容易预料的失败：一个"自己判断问够了"
的模型永远会提前收工。

## 一、职责划分

| 由规则决定 | 由模型决定 |
| --- | --- |
| 哪些问诊轴是**必答**的 | 问什么、用什么措辞、什么顺序 |
| 哪些轴与本例**相关**（年龄、性别、主诉词） | 在一个轴上追多深 |
| 红旗轴**永远不可跳过** | 哪句题库原文直接用、哪句要改写 |
| 什么时候允许结束（审核者裁决） | 是否**提议**结束（提议会被复核） |

模型比固定问卷强的地方，正是它能顺着上一轮答案追下去：病人说"走两百米就得停"，
下一问应该是**"停下来是站着缓解还是弯腰缓解"**——因为这一问才把神经源性跛行与血管源性
分开。固定问卷做不到，因为鉴别性的下一问取决于上一问的答案。

## 二、28 条问诊轴

`yaobi_harness/interview/axes.py`。每条轴带：层级、传统出处、闭合它需要哪些事实、
专业依据、题库、适用条件、以及哪个角色能回答。

```bash
python -m yaobi_harness interview                     # 全表
python -m yaobi_harness interview --tier RED_FLAG     # 按层级
python -m yaobi_harness interview --axis claudication # 单轴详情
python -m yaobi_harness interview --complaint "68岁女性腰痛3月，走远了要停"
```

### 层级决定后果，不只是排版

| 层级 | 条数 | 未闭合的后果 |
| --- | --- | --- |
| `RED_FLAG` | 5 | **阻断任何含剂量放行** |
| `CORE` | 4 | 阻断含剂量放行 |
| `SPECIALTY` | 6 | 不阻断，但缺了就无法把病因真正分开 |
| `TCM` | 10 | **开方前必答**（`prescriptive` 时纳入必答层） |
| `CONTEXT` | 3 | 影响方案，不阻断 |

### 十问歌不是装饰

> 一问寒热二问汗，三问头身四问便，五问饮食六胸腹，
> 七聋八渴俱当辨，九问旧病十问因，再兼服药参机变，
> 妇女尤必问经期，迟速闭崩皆可见。

十条全部落成了轴（`tradition: 十问歌`），而且每条都对应一个真实的用药决策：
寒热定方药温凉、二便分虚实、饮食决定脾胃能否耐受苦寒滋补、服药是骨科最高频的
可预防伤害来源、经期同时是妊娠禁忌的必要信息。测试里有一条专门校验这十条都在
（`test_ten_questions_song_is_actually_covered`）——这是代码要兑现的承诺，不是文档里的说法。

### 骨科专科的六条鉴别轴

`pain_character`（OPQRST）、`inflammatory_vs_mechanical`（ASAS 特征：晨僵>30min、
活动后缓解、后半夜痛醒、<40 岁起病）、`radiation_dermatome`（L4/L5/S1 与 C6/C7 定位）、
`claudication`（前屈缓解 vs 站立即缓解）、`myelopathy`（手笨拙与步态不稳）、
`trauma_surgery_implant`（受伤能量与植入物）。

`bone_fragility` 单列，覆盖 FRAX 要素与椎体压缩线索；50 岁以上或提到骨质疏松时自动纳入。

## 三、追问怎么发生

模型通过 **`ask_patient` 工具**提问，而不是输出一段文字让系统去解析。这一点决定了提问是
模型的**动作**，而不是系统的**排版**——每个问题必须声明它要闭合哪条轴。

五道闸门，每一道都是真实的拒绝路径：

1. **结构** —— 问题必须带已知 `axis_id`；否则整条丢弃。
2. **覆盖** —— 必答轴被漏掉时，从题库补回，并在 `rejected` 里留痕。模型选措辞，规则选范围。
3. **只提问** —— 夹带诊断、治疗建议或剂量的问题被丢弃。提问不是告知的通道。
4. **预算** —— 每轮至多 4 问，每次问诊至多 6 轮。
5. **回退** —— 模型不可用、崩了、超预算，一律回落题库。措辞退化，覆盖不退化。

## 四、什么时候可以停：五种裁决

`yaobi_harness/interview/adequacy.py`。模型说"问够了"只是**提案**，由一个独立的
审核者按苛刻的骨科主任标准复核。

| 裁决 | 含义 | 处理 |
| --- | --- | --- |
| `achieved` | 审核者同意 | 继续下一步，不再追问 |
| `not_achieved` | 仍有具名缺口 | 带着缺口再问一轮 |
| `stalled` | **连续三轮**缺口完全相同 | 带缺口继续，缺口记录在案 |
| `cap_reached` | 达到轮次上限 | 同 `stalled` |
| `blocked` | 必答轴仍未闭合 | **不得进入含剂量或处方环节**，永不可豁免 |

`blocked` 是这个模式的临床反转。软件里的同类设计（目标完成分类器）在基础设施故障时
**fail open**——卡住的目标比误判完成更糟。这里对红旗反过来：马尾筛查没得到答复，
任何裁决、任何上限、任何审核者故障、任何模型意见都不能放行含剂量结果。

其余一律 fail open，因为**把病人困在无尽问卷里同样是临床伤害**。

停滞阈值是 3 而不是 2：两轮相同其实只是**一次**无效交流，而病人一次答一件事是正常配合。
阈值为 2 时，普通对话的第二轮就会被判 `blocked`。

## 五、否定回答也是回答

这是实现中最容易漏、后果最严重的一条。

病人说"大小便正常，没有发烧，腿不麻"——如果系统只记录**阳性**症状，
这三条轴就永远不闭合，于是下一轮再问一遍，再下一轮再问一遍，
最后被判 `blocked`。一个完全配合的病人被系统判定为"病史不足，不能开方"。

所以抽取器显式区分：

* `报告` —— 症状存在
* `否认` —— 明确回答了没有
* `既往报告` —— 历史阳性（"以前查出过肿瘤"）

分类**复用 `safety/red_flags.py` 里既有的从句级否定逻辑**，而不是另写一套。
第一版另写了一套，结果 "没有发烧盗汗，腿没有越来越无力" 被读成两项阳性，
把一个否认一切的病人升级成了急症——这正是那个模块存在的原因。

顺带修掉了筛查层的两个真实缺陷：

* **口语否定**。`NEGATION_CUES` 是按病历书写习惯调的（"无夜间痛"），
  而病人说的是"晚上不会痛醒"。加入 `不会/不太/没怎么/从来不/从没`，
  但对**能力类词**（走路、排尿、抬脚）不适用——"不会走路"是残疾，不是否认。
* **被否认的佐证仍在促级**。`SOFT_CORROBORATION` 原先在全文里做子串匹配，
  于是"没有发热"能把别处的软信号促成硬信号——否认成了它所否认之事的证据。
  现在佐证也是从句级的，并且要经过同一套分类。

## 六、看得见

### 控制台「对话问诊」

左栏顶部是覆盖率环 + 分层进度条 + 按层分组的轴清单：`✓` 已闭合、`!` 必答未闭合、`○` 可选未闭合。
悬停显示该轴的专业依据。问题气泡带层级前缀（`红旗·…`），操作者一眼能看出这一问的紧急程度。

「单次运行 → 问诊与会诊」标签页给出完整审计：充分性裁决与理由、本轮每个问题的
轴/来源/为什么问、被拦下的提问、以及分层覆盖表。

### 命令行

```bash
python -m yaobi_harness chat --role patient \
  --message "腰痛3个月，久坐加重" \
  --message "大小便正常，没有发烧，腿不麻，晚上不痛" \
  --message "63岁，没怀孕，肝肾功能正常，在吃布洛芬和华法林，没有过敏"
```

每轮打印：`第N轮 覆盖X% 判定=… 提问来源=模型/题库`，以及必答未闭合清单与被拦下的提问。

### API

`POST /api/chat` 返回 `interview`（本会话累计）与 `reply.interview`（本轮），
`reply.structured_questions` 带每个问题的 `axis_id`/`tier`/`why`。

## 七、已知限制

* **模型不能主动发起轮次**：追问随回复给出，系统不会自己"打电话"过来。
* **规则回退抽取器覆盖有限**。它认得否定回答、起病、部位、行走距离、晨僵、VAS/ODI、
  职业、睡眠；更口语的表述需要模型抽取。宁缺勿错。
* **`blocked` 不会阻止对话继续**，它只阻止含剂量放行。病人随时可以补答，裁决随之改变。
* 轴的相关性判断基于关键词与年龄性别，不做语义理解；判断错的代价是多问一轮，
  所以刻意偏向"多纳入"。
