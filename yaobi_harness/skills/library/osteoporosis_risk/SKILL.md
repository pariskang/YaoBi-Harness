# 骨质疏松与脆性骨折风险

骨质疏松在骨科门诊最常见的失败模式不是"没诊断出来"，而是**病人因为脆性骨折来看病，
处理了骨折，没有处理骨质疏松**。所以这个技能的第一句话是：

> 一次低能量骨折（平地跌倒、弯腰、咳嗽即骨折）本身就是骨质疏松的临床诊断依据，
> 不需要等骨密度。

## 一、必须采集的 FRAX 要素

风险评估不能只看一个 T 值。要问齐：

| 要素 | 为什么 |
| --- | --- |
| 年龄、性别 | 风险的最大单一决定因素 |
| 身高、体重（BMI） | 低 BMI 是独立危险因素 |
| 既往脆性骨折史 | 最强预测因子；发生过一次，再发风险数倍 |
| 父母髋部骨折史 | 遗传背景 |
| 现在吸烟 | 独立危险因素 |
| 糖皮质激素 | 现用或曾长期用（口服 ≥3 个月）都算 |
| 类风湿关节炎 | 独立于激素的危险因素 |
| 继发性骨质疏松 | 甲旁高、甲亢、性腺功能减退、慢性肝病、吸收不良、1 型糖尿病 |
| 每日饮酒 ≥3 单位 | 独立危险因素 |
| 股骨颈骨密度（如有） | 有则用，没有也能算 |

对应问诊轴：`bone_fragility`。用 `interview_axis_lookup(axis_id="bone_fragility")`
可以取到题库。

## 二、椎体压缩骨折的临床线索

椎体骨折三分之二是无症状的，靠"痛不痛"筛不出来。要靠这几条：

* **身高下降**：比年轻时最高身高矮 >4 cm，或一年内矮 >2 cm
* **驼背加重**：胸椎后凸外观改变
* **肋骨-骨盆间距**缩短（<2 横指）
* **枕墙距**增大
* 突发背痛，与轻微用力（弯腰、提物、咳嗽）相关
* 影像上椎体前缘高度低于后缘（翻拍照片上常不可判读，需正式阅片）

## 三、必须做的实验室与影像

在启动抗骨吸收治疗**之前**，以下几项不是"最好查一下"，而是"不查就不能开始"：

* **血钙（校正钙）与 25-OH 维生素 D** —— 低钙或维 D 缺乏时使用地舒单抗
  可导致严重低钙血症。这是明确的用药前置条件。
* **肾功能（eGFR）** —— 双膦酸盐在 eGFR 低于阈值时禁用/慎用；地舒单抗不经肾清除，
  是肾功能不全时的常见替代考虑。
* **碱性磷酸酶、血磷** —— 排除 Paget 病、骨软化。
* **必要时排除继发因素**：甲状旁腺激素、TSH、血清蛋白电泳（骨痛+贫血+肾损时警惕多发性骨髓瘤）、
  性激素。
* **DXA（腰椎+股骨颈）** —— 有则记录 T 值与测量日期；注意严重退变与压缩骨折会
  **虚高**腰椎测值。
* **胸腰段侧位片或 VFA** —— 身高下降/驼背者用于查找无症状椎体骨折。

## 四、治疗顺序的几条硬约束

这个技能**不开处方**（方剂与剂量工具对它不可达），但必须把顺序性的安全约束讲清楚，
因为顺序错了会直接造成伤害：

1. **先纠正钙与维生素 D，再启动抗骨吸收治疗。** 顺序颠倒是地舒单抗相关严重低钙血症的
   主要原因。
2. **地舒单抗不能随意停药。** 停药后骨转换反跳，存在多发椎体骨折风险，
   停用必须有后续衔接方案。这一条必须写进任何涉及地舒单抗的意见里。
3. **罗莫索单抗在近期心肌梗死或脑卒中患者中禁用**（通常指近一年内）。
4. **双膦酸盐口服**要求空腹、大量清水、服后保持直立 30 分钟以上；
   与钙/铁/镁/铝制剂螯合，必须间隔给药；活动性食管疾病或不能保持直立者禁用口服。
5. **特立帕肽**有疗程上限，且既往有骨骼放疗、骨恶性肿瘤、高钙血症时需排除。
6. **牙科评估**：拟长期使用抗骨吸收药物者，先处理需拔牙的病灶（下颌骨坏死风险）。
7. **糖皮质激素相关骨质疏松**要按更低的干预阈值处理，不能沿用一般人群阈值。

用 `drug_label_lookup` 与 `drug_interaction_check` 核实上述每一条时，
必须在 `evidence_note` 里写明说明书版本与检索时间；没有授权说明书支持时，
如实标注"未获授权说明书背书"。

## 五、跌倒风险：与骨强度同等重要

骨折 = 骨强度不足 × 跌倒。只处理前者是做了一半。

问清：近一年跌倒次数、有无跌倒后不能自己起身、有无头晕/体位性低血压、
视力、多重用药（尤其镇静催眠、抗胆碱、降压）、居家环境（地毯、门槛、卫生间扶手、夜间照明）、
是否用助行器、Timed-up-and-go 或起立-行走能力。

镇静催眠药与抗胆碱负荷是**可逆**的跌倒危险因素——这是最容易被忽略也最容易干预的一项。

## 六、输出

符合 `BiomedicalAssessment` 的 JSON：

* `differentials` —— 按"先排除危险、再考虑常见"排列：病理性骨折（转移瘤、骨髓瘤）、
  骨软化、甲旁高、Paget 病，之后才是原发性骨质疏松。
* `exam_advice` —— 具体到"查什么项目、为什么、什么阈值需要处理"。
* `evidence_note` —— 说明依据来源与强度；占位数据源必须明说"未获授权指南背书"。

不要输出任何克数。
